# 一、备忘清单页 UI 设计关键词
## 风格基调
极简干净、轻量化、待办导向、低干扰、清爽留白、工具感轻量化

## 布局结构
列表流式布局、分组折叠收纳、顶部搜索筛选、底部悬浮新增按钮、分类标签栏、置顶条目区、已完成置底、时间线分组

## 视觉元素
单选勾选框、待办圆点标记、完成线划删除、优先级色块标签、日期小字备注、左滑操作栏、拖拽排序指示器、空状态插画、角标计数

## 色彩体系
主色低饱和蓝/薄荷绿、未完成纯黑正文、已完成浅灰+删除线、紧急项橙红高亮、分组区分浅色块、背景纯白/极浅米白

## 交互细节
一键勾选完成、长按拖拽排序、下拉刷新、左滑删除/置顶/归档、顶部批量多选、折叠归档清单、弹窗快速新建

## 质感风格
扁平化微阴影、大圆角卡片、细分割线、无冗余装饰、极简图标、可折叠面板

# 二、编辑清单页 UI 设计关键词
## 风格基调
专注编辑、沉浸式输入、结构化排版、层级清晰、编辑友好、轻量化编辑器

## 布局结构
顶部标题栏、标题输入框、正文多行编辑区、工具栏悬浮/底部固定、插入功能弹窗、实时预览分栏、字数统计右下角

## 视觉元素
加粗/斜体/列表图标、缩进层级符号、分割线组件、图片插入占位、标签添加胶囊按钮、光标高亮、选中文字浮窗菜单

## 色彩体系
编辑区纯白底色、输入文字深灰、辅助功能图标浅灰、高亮选中淡蓝蒙版、按钮主色突出、次要操作弱化色

## 交互细节
实时自动保存、撤销/重做快捷键、插入清单条目、换行自动生成序号、文本选中唤起格式菜单、退出弹窗二次确认、模板快速插入

## 组件关键词
富文本工具栏、层级缩进器、条目增删按钮、附件上传入口、标签选择器、时间拾取器、字数统计、草稿自动缓存、返回保存提示

# 通用区分精简版
**备忘清单页**：列表、勾选、排序、归档、筛选、新增悬浮按钮、条目卡片、完成态、分组收纳
**编辑清单页**：富文本、标题输入、格式工具栏、层级缩进、插入元素、自动保存、沉浸式编辑、文本排版
