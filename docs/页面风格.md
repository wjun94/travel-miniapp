# 6套旅游小程序完整UI方案（含：主题色+整体页面背景色+页面风格+UI风格）
## 方案1 森系自然清新风｜旅行搭子/露营/周边徒步
### 色彩配置
- 主色：`#4A9C7D` 森林墨绿
- **页面整体背景色：#F5F9F6（浅抹茶色，全局统一背景）**
- 强调色：`#FFC876` 暖杏橙（按钮、热门标签、价格高亮）
- 中性文字：标题`#333333`、正文`#666666`、辅助`#999999`、危险`#E65C5C`
- 卡片背景：`#FFFFFF`

### UI设计风格
扁平化INS简约风 + 细线性图标
1. 卡片圆角`10r`，搭配轻微柔和阴影，拒绝厚重深色阴影
2. 页面大量留白，模块间距规整统一，视觉干净舒适
3. Banner多用山野、露营风景图，可叠加主色10%–15%透明渐变蒙版
4. 标签采用「主色浅底色+深色文字」，热门活动用暖橙色突出层级

### 适配页面
结伴发布、营地预订、徒步路线、游记圈子、个人中心

## 方案2 晴空海盐极简商务风｜景区导览/城市文旅/门票预订（毕业设计首选）
### 色彩配置
- 主色：`#3688C7` 晴空蓝
- **页面整体背景色：#E8F2FB（浅天蓝色全局背景）**
- 强调色：`#FF9A63` 珊瑚橙（提交、预约、立即购买按钮）
- 卡片背景：`#FFFFFF`

### UI设计风格
轻商务扁平化UI，官方稳重风
1. 布局对称规整，模块分割清晰，适合地图、表单、订单、列表页
2. 统一细线条商务图标，无渐变、无卡通花哨装饰
3. 支持顶部蓝白线性渐变导航栏，整体低饱和不刺眼
4. 按钮分两类：填充主色主按钮、描边主色次要按钮，视觉层级清晰

### 适配页面
景点导览、语音讲解、票务预约、订单管理、投诉反馈

## 方案3 暖橘治愈生活化风｜亲子研学/美食旅行/农家乐民宿
### 色彩配置
- 主色：`#F27C4A` 日落暖橘
- **页面整体背景色：#FFF3EB（浅米橘全局背景）**
- 平衡辅助色：`#597C6B` 低饱和墨绿
- 卡片背景：`#FFFFFF`

### UI设计风格
柔和大圆角生活化种草UI
1. 卡片圆角`12r~16r`，极淡阴影，弱化尖锐棱角，亲和力强
2. 可搭配简约手绘线性小插画（民宿、美食、小风景）点缀
3. 大图优先布局，侧重场景氛围感，适合用户种草、评价展示
4. 价格、预约、报名按钮统一用暖橘色做视觉引导

### 适配页面
民宿预订、美食探店、亲子活动、采摘体验、周边农家乐

## 方案4 原木莫兰迪新中式风｜古镇文旅/乡村旅游/非遗体验
### 色彩配置
- 主色：`#A67C52` 原木棕
- **页面整体背景色：#F7F2EB（米杏色全局背景）**
- 点缀色：`#739E86` 苔青色
- 卡片背景：`#FFFFFF`

### UI设计风格
国风莫兰迪低饱和文艺扁平化
1. 无高饱和亮色，整体温润素雅，可搭配极浅宣纸纹理背景
2. 使用中式线性图标：山水、古建、卷轴、油纸伞简约线条样式
3. 宽松留白，细分割线分区，少量中式简约纹样轻微装饰
4. 卡片阴影极淡，营造慢节奏古镇、乡村氛围感

### 适配页面
非遗体验、古镇打卡、乡村民宿、地方特产、民俗路线

## 方案5 韩系清透INS薄荷风｜小众打卡/青年旅行搭子/游记社区
### 色彩配置
- 主色：`#86B89E` 薄荷青柠绿
- **页面整体背景色：#FAFDFB（极浅薄荷白全局背景）**
- 点缀色：`#FFD175` 浅杏黄
- 卡片背景：`#FFFFFF`，可做低透明度毛玻璃效果

### UI设计风格
玻璃拟态+轻渐变韩系简约风
1. 卡片圆角12r，支持轻微毛玻璃、低透明度渐变，通透柔和
2. 沉浸式大图Banner，游记采用朋友圈式卡片布局
3. 纤细极简线性图标，弱化强商业按钮，侧重氛围感
4. 整体配色温柔护眼，年轻化、高级不撞款

### 适配页面
城市小众打卡、图文游记、同城结伴、兴趣话题广场

## 方案6 马卡龙活力度假风｜海岛游/短途团购/旅游线路商城
### 色彩配置
- 主色：`#54B9D1` 浅度假蓝
- **页面整体背景色：#F8FCFE（极浅冰蓝全局背景）**
- 辅助点缀色：`#FFD478`、`#FF9696`
- 卡片背景：`#FFFFFF`

### UI设计风格
马卡龙扁平化休闲卡通风
1. 柔和低饱和明亮配色，活泼不刺眼，度假氛围感拉满
2. 圆角卡片，可搭配云朵、太阳、行李箱等简约小卡通装饰
3. 首页多用宫格分类布局，适合线路、酒店、门票多品类展示
4. 活动Banner搭配柔和渐变背景，突出团购、优惠活动

### 适配页面
旅游线路、酒店团购、热门目的地、限时优惠、优惠券商城

# 通用全局UI规范（所有方案统一标准）
1. 导航栏：白色导航，黑色居中标题
2. 底部Tab：未选中`#999999`，选中色为项目主色
3. 卡片统一：白色底色、圆角8–16r、柔和浅阴影
4. 字体规范
   - 标题：16–18px `#333` 加粗
   - 正文：14px `#666`
   - 辅助文字：12px `#999`
5. 分割线：统一 `#EEEEEE`
