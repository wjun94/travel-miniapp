# 旅游攻略小程序等级体系完整方案
适配：攻略发布、结伴搭子、行程规划、帖子评论全场景，共6大等级，成长靠行为积分，搭配专属权益、身份标识、流量扶持，兼顾活跃度与优质内容激励，区分水号和真实出行用户。
## 一、整体规则总览
1. 成长核心：**经验值升级**，经验只增不减；无降级机制，鼓励长期使用。
2. 积分双体系
    - 经验值：决定等级，永久有效
    - 旅游币：独立积分，可兑换置顶、曝光、模板等权益，可消耗
3. 行为区分：优质内容高经验，灌水评论低经验，恶意操作倒扣经验+旅游币

## 二、等级划分（6级，命名贴合旅行）

## 三、经验值获取明细（所有操作统一标准）
### （一）日常基础行为（每日有上限，防止刷分）
|行为|单次经验|每日上限|补充说明|
| ---- | ---- | ---- | ---- |
|每日登录|+5|每日1次|连续登录额外：3天+3，7天+8|
|浏览任意攻略/搭子/行程|+1|单日最多20次|只有效阅读，快速划过不计入|
|正常评论（≥5字）|+2|单日上限10次|表情/纯标点不算，判定灌水无经验|
|给帖子点赞/收藏|+1|点赞上限15次，收藏上限10次|自己帖子点赞无经验|

### （二）核心创作（高经验，鼓励产出，区分普通/优质）
1. 发布普通内容（文字简单、图片＜3张）
- 普通攻略：+30经验
- 搭子结伴帖：+25经验
- 简易行程（天数≤2天）：+25经验
2. 优质内容（系统自动判定，满足任意2条：配图≥4张、字数≥200、标注路线/花销/避坑）
- 优质攻略：+80经验
- 靠谱搭子（写明时间地点费用规则）：+60经验
- 详细多日行程（≥3天，含食宿交通）：+60经验
3. 内容正向反馈（被动涨经验，优质内容复利）
- 自己帖子被点赞：每20赞+10经验（单篇上限100）
- 自己帖子被收藏：每10收藏+15经验（单篇上限150）
- 评论被楼主回复认可：+3经验/次

### （三）社交互动加分
- 成功匹配搭子并双方确认结伴：一次性+50经验
- 行程帖子被他人复制复用：每次+20经验

### （四）扣分规则（违规风控）
1. 灌水评论、广告、辱骂：单次扣10经验，严重扣50
2. 抄袭搬运他人攻略、盗图：扣100经验，限制发布3天
3. 恶意引战、虚假搭子骗聊：扣200经验，等级权益冻结7天
4. 重复刷屏发帖：当日所有发帖经验清零

## 四、各等级分层权益（攻略/搭子/行程全场景适配）
### Lv1 初旅路人
1. 基础权限：可浏览全部内容、正常评论、点赞收藏
2. 限制：每日最多发2条帖子（攻略/搭子/行程合计），无发帖置顶权限
3. 福利：免费使用基础简易行程模板3套

### Lv2 闲游旅人
1. 发帖上限提升：每日可发4篇内容
2. 评论特权：评论区自带Lv2蓝色标识，更容易被楼主看见
3. 工具：解锁城市小众景点简易清单模板；每周免费1次行程自动排版
4. 流量：发布搭子帖轻微加权曝光

### Lv3 漫游行者（大众主力等级）
1. 无每日发帖条数限制
2. 权益：
   - 帖子支持添加标签置顶（个人主页置顶免费）
   - 发布行程可使用时间轴、花销表格高级排版
   - 评论可发图片，普通用户Lv1/Lv2评论不能配图
3. 流量扶持：攻略、搭子进入同城推荐池基础曝光+20%
4. 额外：可创建长期固定结伴圈子

### Lv4 山河探客（攻略核心创作者）
1. 全部Lv3权益，额外：
   - 每月3次免费全站帖子短期置顶（每次6小时）
   - 发布攻略自动优先进入首页精选推荐
   - 搭子帖子标记「靠谱达人」标签，更容易被人组队
2. 工具全开：全部行程模板、预算计算器、交通规划插件免费
3. 流量：原创攻略曝光+50%；行程帖被更多人搜到
4. 特权：可给评论区不良内容发起举报加急处理

### Lv5 环球旅记（旅行达人）
1. 所有Lv4权益拉满，置顶次数升级：每月8次免费置顶
2. 专属标识：首页帖子自带「旅行KOL」金边，辨识度拉满
3. 运营扶持：优质攻略平台人工收录，永久归档；官方定期转发
4. 搭子特权：发布结伴自动优先匹配精准同需求用户；可设置搭子入帖门槛
5. 变现辅助：开放攻略好物、本地店铺种草合规挂载权限

### Lv6 万里旅神（顶级用户）
1. 不限次数免费帖子置顶；专属金色动态头像框
2. 平台定制：可申请专属旅行话题，官方流量倾斜
3. 搭子&行程优势：发布的结伴、路线全网最高权重；支持批量发布多城市行程
4. 定制权益：专属客服；节日免费旅游周边兑换；优质内容可申请平台流量推广包
5. 社区权限：拥有优质内容举荐权，可推荐普通用户攻略上精选

## 五、配套成长玩法（提升活跃度）
### 1. 旅行成长任务（每周刷新，额外拿经验+旅游币）
|周任务|奖励|
| ---- | ---- |
|发布1篇带图攻略|经验+40，旅游币+20|
|成功约到搭子出行确认|经验+60，旅游币+35|
|完成3次有效评论互动|经验+20|
|新建一份3天以上完整行程|经验+45|

### 2. 旅游币使用渠道（和等级挂钩，等级越高兑换越划算）
- 帖子付费置顶、加急曝光
- 解锁小众城市独家行程模板、美食避坑清单
- 搭子帖子精准推送（定向同城、同年龄段）
- 兑换头像框、旅行专属徽章皮肤

### 3. 季节旅行加成
节假日（寒暑假、国庆、五一）发帖、结伴经验加成20%，鼓励旺季产出出行内容。
