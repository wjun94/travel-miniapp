# 搭子创建页 + 搭子详情页全功能清单（适配旅游/通用搭子小程序）
整体分为**创建发布功能**、**详情浏览通用功能**、**发起人专属管理功能**、**参与者操作功能**、社交配套、进阶特色六大模块。

## 一、搭子创建（发布页）所有功能
### 1. 基础必填信息区
1. **搭子标题**：自定义活动名称，支持字数限制
2. **活动类型分类**：旅游、美食、运动、学习、探店、看展、桌游等多标签可选，支持多选自定义标签
3. **时间设置**
    - 出发/集合日期、起止具体时分
    - 旅行可填多天行程；支持选择工作日/周末、全天/半天
    - 可设置活动提醒时间（提前1天/3小时推送通知）
4. **地点设置**
    - 地图选点：城市、详细集合地址，一键导航
    - 旅游搭子可填途经多地、目的地全程点位
    - 支持填写线上（腾讯会议）无实体地点
5. **人数管控**
    - 总人数上限、当前招募空位；可设置男女比例限制（如2男2女）
    - 最小成团人数，未满员可自动延期/取消提醒

### 2. 费用&规则填写
1. 付费模式：免费、AA制、组织者全包、人均固定预算
2. 费用明细：费用包含项、不含项、预估总价，旅游可罗列门票、住宿、交通开销
3. 详细介绍：富文本输入，写行程安排、玩法、出行装备、忌口、注意事项
4. 招募门槛（伙伴要求）：年龄区间、性格偏好、经验要求、是否会拍照、能否早起、有无晕车等限制

### 3. 素材与标签
- 封面图+多图上传，支持短视频，展示目的地/玩法实拍
- 自定义兴趣标签：徒步、拍照、美食、穷游、特种兵旅行等，提升匹配推荐

### 4. 发布权限设置（隐私管控）
1. 可见范围：全部用户可见 / 仅同城可见 / 仅好友可见
2. 入群模式：无需审核直接加入 / 需要发起人手动审核报名申请
3. 成团开关：人数满员自动关闭报名，不可再申请
4. 允许他人转发、允许收藏开关

### 5. 发布操作按钮
草稿保存、预览搭子详情、正式发布、一键清空表单；发布成功自动推送广场信息流。

## 二、搭子详情页：全员可见基础展示功能
### 1. 顶部基础信息卡片
- 封面大图、搭子完整标题、活动类型标签
- 时间、集合地址（一键跳转地图导航）、距离本人公里数
- 费用方式、人均预算、总人数/已报名人数/剩余空位
- 搭子状态：招募中 / 已成团 / 进行中 / 已结束 / 已取消

### 2. 发起人板块
发起人头像、昵称、简介、信用评分、过往搭子评价；可点击进入发起人主页、发起私聊。

### 3. 完整详情内容
1. 完整文字介绍：行程日程、装备清单、出行规则、饮食禁忌
2. 所有上传图片、视频轮播浏览
3. 自定义标签全部展示

### 4. 参与人员列表
所有已通过报名的搭子，展示头像昵称、简单兴趣标签；支持查看单个搭子主页。

### 5. 公共互动区
- 评论讨论区：所有人留言提问、协商细节，发起人可置顶重要通知
- 点赞、收藏、分享（微信好友、朋友圈、小程序卡片）
- 举报入口（违规、广告、虚假信息）

## 三、详情页：发起人（创建者）专属管理功能
1. **报名审批管理**
    查看所有报名申请，同意通过/拒绝报名，可填写拒绝理由；批量处理申请。
2. **搭子编辑**
    随时修改标题、时间、地点、人数、行程、费用、招募要求；修改后全员推送变更通知。
3. **成团操作**
    手动提前截止报名；人数不足手动取消搭子；活动结束手动归档。
4. **成员管理**
    移出不合适参与者、拉黑用户；给全员发统一公告。
5. **群聊创建**
    一键生成搭子专属群，所有已入队成员自动进群；群入口固定在详情页。
6. **售后评价管理**
    查看所有参与者给自己的评价，可回复评价；活动完结开启互评通道。
7. 紧急联系人、行程备忘录编辑权限

## 四、详情页：普通参与者（报名用户）操作功能
1. 核心按钮：**立即报名**，报名可填写个人备注（比如“会开车、可拍照”）；已报名状态变为「已加入」。
2. 取消报名：招募期内可自主退队，发起人收到退队通知。
3. 联系能力：私聊发起人、私聊其他搭子；进入搭子群聊天。
4. 辅助工具：收藏搭子、分享给好友、导航到集合点；开启活动日历提醒。
5. 活动结束后：对发起人、同行搭子打分评价（守时、靠谱、好沟通），填写文字口碑。
6. 可查看自身报名记录、过往参与记录。

## 五、通用配套社交&工具功能（详情页内嵌）
1. 位置共享：群内/详情页临时共享实时位置，线下集合防迷路
2. 行程台账：旅游搭子可查看时间轴日程，标注每日景点、住宿、交通
3. AA记账：多人费用记账，自动分摊账单明细
4. 消息推送：时间改动、新成员加入、发起人发公告、活动快开始全量提醒

## 六、进阶特色功能（旅游搭子专属）
1. 行程复用：发起人可把本次行程保存为模板，下次创建搭子一键复用
2. 投票功能：成团后在详情页发起投票（改路线、换餐厅、调整出发时间）
3. 相册共建：所有搭子可上传旅途照片，统一汇总在搭子详情相册
4. 安全模块：一键留存紧急联系人，一键报备亲友行程

## 七、搭子全生命周期状态流转
创建草稿 → 发布招募中 → 审核成团 → 活动进行 → 完结归档；发起人随时可主动取消，人数不足系统可自动超时关闭招募。
