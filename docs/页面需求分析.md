# 旅游微信小程序需求功能文档 (PRD) & 变现方案

## 一、 产品概述与生态定位

基于**微信小程序生态**打造的一站式旅游社交与工具平台。利用微信的强社交关系（找搭子、行程分享）、便捷的地理位置能力（周边游、足迹地图）以及无需下载的优势，为用户提供“旅前规划、旅中记录、旅后分享”的完整闭环。

---

## 二、 底部 5 大 Tab 架构设计（微信小程序端）

```
[ Tab 1：攻略 ]   [ Tab 2：周边游 ]   [ Tab 3：发布攻略(+) ]   [ Tab 4：消息中心 ]   [ Tab 5：我的 ]

```

* **Tab 1：攻略（首页）** —— 小程序主界面。采用双列瀑布流展示图文攻略，顶部高亮【寻找搭子】社交入口。
* **Tab 2：周边游** —— 调取微信底层 GPS 定位，推荐用户当前所在城市周边的短途游、周末好去处。
* **Tab 3：发布攻略（+）** —— 核心功能枢纽。支持发布 UGC 攻略与创建“AI/手动”行程，支持分享给他人编辑，展示目的地未来 7 天天气。
* **Tab 4：消息中心** —— 承载微信用户间的搭子组队申请、私聊消息及行程协同通知。
* **Tab 5：我的** —— 自由行工具箱（记账、备忘）与可视化个人履历（微信足迹地图）。

---

## 三、 核心模块详细需求与小程序特有优化

### 3.1 Tab 1：【攻略】模块（首页）

* **寻找搭子（核心亮点）：**
* **微信裂变卡片：** 找搭子的卡片支持**一键分享到微信群/微信好友**。卡片展示：目的地、出发时间、当前人数、搭子要求。
* **一键微信授权组队：** 浏览者点击“申请加入”，通过微信订阅消息通知发起人，同意后自动在 Tab 4 建立双人会话。



### 3.2 Tab 2：【周边游】模块

* **微信定位沉浸式体验：** 自动唤起微信定位权限，根据距离推荐 2 小时车程内的景区、民宿。
* **【新增完善功能】一键直达导航：** 点击周边游景点，可直接拉起微信内置的地图（腾讯地图/高德/百度）进行驾车或公交导航。

### 3.3 Tab 3：【发布攻略】模块（双轨制行程创建）

点击 “+” 号，顶部切换：【发动态/攻略】与【写行程】。

#### 【写行程】流程细化：

1. **基础选择：** 输入地址（支持调用微信城市选择器），选择“具体日期”或“总天数”。
2. **双轨制生成：**
* **AI 创建：** 输入地址和天数，勾选偏好（特种兵、慢游、亲子），AI 一键输出每日行程（含景点、餐厅、游玩时长）。
* **自己编辑（手动）：** 自由“添加天数”。单日内点击“+”可**连续添加多个行程点**（如：酒店 -> 景点A -> 餐厅B -> 景点C）。


3. **【本周天气预报】集成：** 行程单顶部实时展示目的地未来 7 天天气。若选了天数未选日期，则展示当前周天气，并根据天气（如暴雨、高温）对行程点进行智能预警。
4. *【小程序特有完善功能】微信好友协同编辑：* 创建者可以一键生成“行程邀请小程序卡片”发送给微信好友，好友点击后可**共同编辑同一个行程、共同添加行程点**。

### 3.4 Tab 5：【我的】模块（工具箱与个人履历）

* **个人履历（足迹地图）：**
* 利用小程序地图组件，动态渲染中国/世界地图。
* 根据用户发布的攻略定位、或已完成的行程，**自动点亮去过的省份/城市**。
* *【新增完善功能】一键生成朋友圈海报：* 自动将点亮的地图渲染成带小程序码的高清海报，方便用户发朋友圈炫耀，为小程序引流。


* **旅游记账：** 按行程绑定账本。支持交通、餐饮、住宿分类。
* *【新增完善功能】微信记账快捷导入：* 允许用户在记账时，授权并关联当天的“微信支付账单”，快速勾选导入，免去手动输入金额的麻烦。


* **备忘清单（Check-list）：** 代办事项清单，支持勾选、置顶。提供官方模板（如海岛、特种兵必备物品）一键导入。
* *【小程序特有完善功能】微信订阅消息提醒：* 出发前一天，通过微信服务通知提醒用户核对备忘清单，防止漏带身份证等。

有“本周杭州周边游 TOP 1 民宿推荐”，可以在后台编辑，前端显示。
后台可以创建寻找搭子，引入官方认证的“专业领队”、“地接导游”或“小团定制师”。许多用户在找搭子时由于时间凑不齐很难成行，此时推出“官方组团搭子”服务（如：川西7日纯玩搭子团、毕业季特种兵拼车）
